# Projeto GDP — ROV-MB

Este repositório contém a documentação acadêmica do projeto ROV-MB.

ORDEM DAS TAREFAS:
1. Tarefa 1 — TAP
2. Tarefa 2 — EAP + Dicionário
3. Tarefa 3 — Gerenciamento da Qualidade
4. Apresentação documental em HTML

REGRAS:
- Não alterar conteúdo de uma tarefa anterior silenciosamente.
- Tarefa 1 é a fonte-base do escopo.
- Tarefa 2 deve ser compatível com a Tarefa 1.
- Tarefa 2 deve aplicar as críticas do Cmdt Huback e os 10 Mandamentos da EAP.
- Tarefa 3 deve usar a EAP final da Tarefa 2.
- O HTML deve representar os documentos finais, não criar uma nova versão deles.
- Quando houver conflito, identificar o conflito antes de corrigir.
- Preservar histórico das decisões.
